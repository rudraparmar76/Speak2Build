# Alma design system — adapted for Speak2Build

> Adapted from [Inspo](https://github.com/Nutlope/inspo) extraction of alma.food

- **Source:** https://www.alma.food
- **Mode:** light
- **Macrostructure:** Marquee Hero

## Tone

Soft, organic layout with warm earthy palette. Serif headlines for editorial feel. Floating UI cards. Minimalist wellness-inspired design adapted for a developer tool.

## Colors

| Token | Hex | Role |
|---|---|---|
| `kiwi` | `#aadf49` | Primary accent / CTA |
| `collard` | `#3c5627` | Button gradient dark |
| `aioli` | `#f7f5ed` | Light background |
| `teriyaki` | `#33140c` | Dark text |
| `yogurt` | `#fffdf5` | Surface white |
| `surface` | `#fffefc` | Card surface |
| `muted` | `#a1a1a1` | Muted text |
| `teal` | `#146c84` | Accent secondary |

## Typography

- **Display:** GT Alpina Condensed (fallback: Georgia, serif)
- **Body:** Inter / system sans-serif

## Spacing

Base: 4px grid. Scale: 16, 24, 40, 80px.

## Border radius

0, 15, 20, 32, 40, 50px

## Container

Max: 1200px. Padding: 80px desktop, 40px mobile.
